# Ozon.check

Расширение для браузера: забирает заказы из «Мои заказы» на Ozon и отправляет их во «Входящие заказы»
склада [СПРУТ](https://github.com/inestvan/sklad-sprut) («Закупка» → «Заказы из магазинов»). Там владелец отмечает,
что из заказа для склада, и заказ становится посылкой «в пути» (или сразу приходом, если уже получен).

- Работает в вашем браузере, где вы уже вошли в Ozon. Пароль от Ozon не нужен и никуда не передаётся.
- Ничего не делает само: заказы отправляются только по кнопке.
- На склад уходят все заказы из списка, в том числе личные покупки — склад их запоминает как «не для склада»
  и больше не предлагает.

## Установка

Chrome или Яндекс.Браузер на компьютере:

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте, или `git clone`.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное» → папка **`extension`**.
4. Нажмите значок расширения: вставьте адрес склада и ключ (на складе: «Настройки» → «Расширение для браузера»
   → «Создать ключ») → «Сохранить и проверить».
5. Там же галочка **«Только заказы в пути»** (включена по умолчанию): полученные и отменённые заказы
   не отправляются. Снимите её, если нужно отправить и старые, полученные заказы.

Обновление: заменить файлы в папке и нажать «Обновить» на `chrome://extensions`.

## Как пользоваться

На Ozon откройте «Заказы» и нажмите **«📦 В склад СПРУТ»** внизу слева. Расширение прочитает заказы и покажет,
сколько новых ушло на склад. С галочкой «Только заказы в пути» — только «Актуальные», и из них только то, что ещё
не получено («В пути», «Ожидает получения»…); без галочки — ещё и первую страницу «Завершённых». Повторная отправка дублей не создаёт —
у известных заказов обновляется статус.

## Как устроено

| Файл | Что делает |
|---|---|
| `extension/ozon.js` | на `ozon.ru/my/*`: кнопка; читает заказы тем же JSON, что и сама страница Ozon (`/api/entrypoint-api.bx/page/json/v2?url=…`) |
| `extension/background.js` | отправляет на склад (склад дома по http — из страницы Ozon по https такой запрос не пройдёт) |
| `extension/options.*` | адрес склада и ключ (хранятся в `chrome.storage.sync`) |

Что берётся из Ozon: список — `orderList` (`/my/orderlist?selectedTab=active|archive`); заказ — `/my/orderdetails/?order=N`:
дата — `titleWithTimer` («Заказ от 17 октября»), сумма — `orderDoneTotal`, товары и статус — `shipmentWidget`
(код товара `title.common.action.id`, название, атрибуты, цена строки, картинка `picture.image.image`). Отправления со статусом «Отменён» пропускаются, с галочкой «Только в пути» — и «Получен» / «Доставлен»
(сравнивается начало статуса: «Ожидает получения» — это ещё в пути).
Количество Ozon отдельно не отдаёт — берётся «N шт» / «×N» из цены и атрибутов, иначе 1 (на складе можно поправить).

Если Ozon поменяет сайт — кнопка напишет «Не получилось…»; тогда правится `ozon.js`.

### Что получает склад

`POST <адрес склада>/api/shop-orders`, заголовок `X-Sklad-Key: <ключ>`:

```json
{
  "shop": "Ozon",
  "orders": [{
    "number": "91567470-0025", "date": "2026-10-17", "status": "В пути", "amount": 1240,
    "url": "https://www.ozon.ru/my/orderdetails/?order=91567470-0025",
    "items": [{ "sku": "4933578398", "name": "…", "variant": "Черный", "url": "https://www.ozon.ru/product/…/",
                "price": 148, "qty": 1, "image": "https://ir.ozone.ru/s3/…/12556202693.jpg" }]
  }]
}
```

Ответ: `{"ok": true, "new": 1, "updated": 0, "inbox": 3}` или `{"error": "…"}` (401 — ключ не подходит).
`POST /api/ping` с тем же заголовком — проверка из настроек.

## Проверка

```
npm install
npm test
```

Запускает настоящий Chrome (временный профиль) с расширением: Ozon подменён выдуманными заказами, склад — поддельный
сервер в самом тесте. Проверяются настройки (неверный ключ, недоступный склад), «только в пути» и без неё, что именно ушло на склад
и случай «в пути ничего». Chrome не в стандартном месте — `CHROME=путь\chrome.exe npm test`.
